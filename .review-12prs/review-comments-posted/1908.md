First, decomposition, because +13.6k overstates the risk: 11,689 lines are the generated `packages/shell/contract/versions/v2.d.ts` (forced into existence by `shell:freeze --check` the moment the root barrel gains an export), ~1,033 are tests, ~198 docs, 97 lockfile — the hand-written production change is **609 lines**. Two executed P1s and a structural suggestion:

1. **Silent empty rows across a version skew.** An engine that doesn't know `row_mode` returns the right row count with every column missing — `select()` yields `[{}, {}, ...]`, no error (executed via fake transport). SDK and engine ship on different trains and there's no capability negotiation; a ~4-line guard (fail loudly when `row_mode` is requested but absent in the reply) closes it.
2. **Commit succeeds on a discarded transaction — executed on real Postgres 16.** Removing the auto-rollback in `db_instance_base.py` means a failed statement leaves the session open; `begin → unique violation → commit` then returns normally to the client while the server log shows a literal `COMMIT` on an aborted transaction and the write is discarded (`{ok:true}` to the caller, row gone). The inline comment even says "commit degrades to rollback" without surfacing it to the caller. (On sqlite the shape differs — the pre-error write commits — so this is specifically the Postgres contract.) Related: `drizzle-e2e.test.ts` is 297 lines of exactly the right tests, but `ROCKETRIDE_E2E` appears in no workflow — they have never run in CI.

Also: failed statements can pin a pooled connection indefinitely (reaper only runs from `begin()`, and `last_used` refreshes on failure); `Decimal`→float and int8>2^53 are lossy; and `package.json` textually conflicts with #2025, so the two need explicit ordering.

**Recommendation: split engine-first, SDK-second** — the two P1s live on opposite sides of the deploy boundary and the client half hard-requires the server half in production. And one high-leverage option: declaring `DrizzleDatabaseLike` under the `./drizzle` subpath instead of the root barrel avoids minting the 11.7k-line frozen contract at all.
